## 1. 한 줄 요약

Stable Diffusion 1.5에 "a photo of a CEO"를 넣으면 거의 남자만 나온다. 그 이유를 **AI 내부를 시각화해서** 찾아봤고, 텍스트 인코더 안의 '성별 방향' 하나만 움직여도 그림 속 성별이 바뀌는 것을 CLIP 판정으로 확인했다. 이어서 성별 위치를 범위 안으로 자르는 클리핑으로 직업 간 성별 편차를 약 40% 줄였다.

## 2. 투명성 주제와 연결

- AI는 보통 "입력 → 출력"만 보이는 블랙박스다. 결과가 편향돼 있어도 **왜 그런지**는 안 보인다
- 이 프로젝트는 모델 내부(텍스트 인코더)의 숫자를 **그림으로 바꿔서** 편향이 어디에, 언제, 얼마나 있는지 보여 준다
- 보는 것에서 멈추지 않고 내부를 직접 조작해서 **"이게 정말 원인인가"**를 확인했다. 투명성은 설명을 넘어 확인까지 가야 한다는 메시지

## 4. 모델 구조 설명 요령 (3·4번)

### 3번: Stable Diffusion 1.5의 구조

- 사용 모델: `stable-diffusion-v1-5` (fp16). 성별 판정에는 별도의 CLIP `openai/clip-vit-large-patch14`
- 세 부분을 요리에 비유하면 쉽다: **주문서 읽기(텍스트 인코더) → 요리(U-Net) → 담기(VAE)**
  - 텍스트 인코더: CLIP ViT-L/14의 텍스트 부분. 12층을 거쳐 프롬프트를 77칸 × 768개 숫자로 바꾼다
  - U-Net: 노이즈에서 시작해 25단계에 걸쳐 그림을 다듬는다. 매 단계 텍스트 숫자를 참고한다
  - VAE 디코더: 압축된 그림을 실제 픽셀 이미지로 바꾼다
- 강조: **U-Net과 VAE는 그대로 두고, 재학습도 하지 않았다**

### 4번: 어디를, 왜, 무슨 의미

- **어디를**: 텍스트 인코더가 U-Net에 넘기는 최종 출력 중 직업 단어부터 문장 끝까지를 성별 방향으로만 옮겼다(`src/utils.py`의 `intervene`)
  - 옮기는 위치를 **lam**으로 나타낸다: −1 = 여성 단어 평균, 0 = 가운데, +1 = 남성 단어 평균 (기준값 c = −1.19, s = 6.42, 04 셀 1)
  - lam은 9번(같은 시드 격자)에서 처음 보이므로 여기서 꼭 설명하고 넘어가기
- **왜 여기인가**
  1. 프롬프트의 뜻이 처음 숫자가 되는 곳이라 'CEO'의 의미가 여기서 정해진다
  2. 남녀 단어 쌍으로 방향을 만들고 검증할 수 있어 해석이 쉽다(5·6번으로 연결)
  3. 재학습 없이 숫자만 바꿔 원인 → 결과를 비교할 수 있다
- **무슨 의미인가**: 여기만 바꿔도 그림의 성별이 바뀐다면 편향은 AI가 '단어를 읽는 단계'에 이미 담겨 있다. 결과를 좌우하는 내부 숫자를 짚을 수 있다는 것이 투명성의 핵심
- 주의: U-Net 쪽에 편향이 없다는 증명은 아니다. 12번 Discussion에서 다시 언급

## 5. 배경 슬라이드 설명 요령 (5·6번)

### 5번: 성별이 벡터(방향)가 되는 이유

- 비유: 지도에서 "서울 → 부산" 화살표처럼, AI 안에서는 "man → woman"이 하나의 화살표다
- 핵심 문장: **"남자→여자로 바꾸는 화살표가 단어마다 거의 같은 방향이라, 그 공통 방향을 '성별 방향'이라고 부른다"**
- 만든 방법: 7쌍(man/woman, male/female, father/mother, husband/wife, son/daughter, gentleman/lady, boyfriend/girlfriend)의 (남 − 여) 화살표를 평균
- 오른쪽 그림은 개념 도식이고 실제 좌표가 아니다. "king − man + woman ≈ queen"은 유명한 예시로 소개만 하기

### 6번: PCA로 한 검증

- PCA를 쉽게: **여러 화살표를 가장 잘 대표하는 '하나의 방향'을 찾는 방법**. 그 방향이 전체 차이의 몇 %를 설명하는지도 알려 준다
- 결과: 대표 방향 하나가 **56.8%**를 설명 (02 셀 8). 층별로 보면 1층 약 0.3 → 12층 약 0.55로 뒤로 갈수록 한 방향으로 모인다 (02 셀 5 그림, 근사)
  - 비교 기준(이론값, 측정 아님): 7개 화살표가 완전히 제각각이면 약 1/7(약 14%)
- 추가 확인: 방향 계산에 안 쓴 3쌍(brother/sister, king/queen, businessman/businesswoman) 모두 남성 쪽 값이 더 컸다(마지막 층 차이 8.48, 9.30, 10.29)
- 말할 때 주의: PCA는 통계적 유의성 검정(p값)이 아니다. "한 축으로 잘 요약되고, 처음 보는 단어에도 맞았다"고 말한다

## 6. 시연과 실험 슬라이드 설명 요령 (8~11번)

- **8번 시연**: `figures/layer_slider.html`을 브라우저로 미리 열어 두기. PPT의 점선 칸을 클릭해도 열린다(파일 위치가 바뀌면 링크가 깨질 수 있음). 시연이 안 되면 백업 `figures/layer_curves.png`
- **9번 → 10번 순서**: 결과 예시(이미지)를 먼저 보여 주고, "이걸 체계적으로 2,100장 만들어 셌다"며 실험 환경으로 넘어간다
- **CLIP 판정을 쉽게**: 이미지와 문장이 얼마나 어울리는지 점수를 매기는 다른 AI. 각 이미지를 "a photo of a man / a woman / with no person" 세 문장과 비교해 가장 높은 쪽으로 판정했다
- **왜 사람이 안 셌나**: 2,100장이라 자동 판정. 확신 높은 판정만 써도 결과가 거의 같은지 확인(차이 평균 2.3%p)
- **11번 그림 읽는 법**: 파란 선 = 축 위치별 남성 비율, 검은 네모 = 원본, 노란 세모 = 무작위, 빨간 점선 = 50% 지점. 노란 세모가 검은 네모와 거의 겹친다 = 무작위 방향은 효과 없음

## 7. Discussion 설명 요령 (12번, 가장 중요)

- 예상: 0(정가운데)으로 옮기면 남녀 반반이 나올 것
- 실제: 0에서 남성 비율 4~27%로 6개 직업 모두 여성이 다수
- 반반이 되려면 남성 쪽으로 더 밀어야 한다: CEO +0.18, pilot·cashier +0.23, teacher +0.30, nurse +0.42, nanny +0.45
- 의미: 텍스트의 성별 방향 하나로는 설명되지 않는 편향이 남아 있다. 그게 U-Net 쪽인지, 다른 방향인지는 이번 실험으로 구분할 수 없다
- 투명성과 연결: **눈에 보이게 만들었기 때문에 "축 하나를 지우면 해결"이라는 간단한 방법이 통하지 않는다는 사실도 알 수 있었다**
- 주의: lam은 0.5 간격으로만 생성해서 이 값은 두 점 사이를 직선으로 이은 추정이다
- 다음 장으로 넘기는 말: "그래서 0이 아니라 반반 지점 근처로 모아 보는 안전장치를 만들었다"

## 8. 클리핑 설명 요령 (13·14번)

### 13번: 방법과 효과

- **클리핑을 쉽게**: 각 직업의 성별 위치(lam)가 정해진 범위를 벗어나면 가까운 경계로 끌어다 놓는 것. 범위는 +0.2 ~ +0.4
  - 예: CEO +0.67 → +0.4, nurse −0.43 → +0.2
  - 6개 직업 모두 원래 위치가 범위 밖이라, CEO·pilot은 +0.4로, 나머지 4개는 +0.2로 옮겨졌다
- **중심이 0이 아니라 +0.3인 이유**: Discussion에서 반반 지점이 +0.18~+0.45였기 때문
- 효과 (06 셀 6)
  - 직업별 남성 비율 범위: 0.00~0.98 → 0.19~0.82
  - 50%에서의 평균 거리: 0.41 → 0.25 (약 40% 감소)
- 그림 읽는 법 (`clamp_on_curves.png`): 노란 띠 = 클리핑 범위, 검은 네모 = 원본, 빨간 점 = 클리핑 결과, 가로 막대 = 생성 전 예측. 파란 곡선은 05의 lam 곡선

### 14번: 예측, 부작용, 한계

- **예측대로**: 이미지를 만들기 전에 05의 lam 곡선으로 결과를 미리 계산해 노트북에 적어 두었다. 6개 중 5개가 ±0.04 안에서 맞았고 teacher만 예측(0.38)보다 0.19 낮았다(0.19)
  - 투명성과 연결: **내부를 이해하면 결과를 미리 예측할 수 있다**
- **부작용 없음**: CLIP score 변화 0.4 이하라 직업다운 이미지가 유지됐다. lam +1로 크게 옮겼을 때 nanny가 −2.7이었던 것과 비교
- **한계**: 편향 폭은 줄었지만 직업 간 차이는 남는다. CEO·pilot 0.80~0.82, 나머지 0.19~0.44
  - 이유: 범위 경계 두 곳으로 모이다 보니 원래 남성 쪽이던 직업은 +0.4, 나머지는 +0.2에 놓인다
- 그림 (`clamp_grid.png`): 같은 시드로 원본과 클리핑을 나란히 놓았다. 대부분 구도가 같고 일부만 성별이 바뀐다

| 직업 | 원래 lam → 자른 뒤 | 원본 | 예측 | 실제 |
|---|---|---|---|---|
| pilot | +0.54 → +0.4 | 0.92 | 0.76 | 0.80 |
| CEO | +0.67 → +0.4 | 0.98 | 0.79 | 0.82 |
| nurse | −0.43 → +0.2 | 0.00 | 0.26 | 0.22 |
| nanny | −0.40 → +0.2 | 0.05 | 0.27 | 0.24 |
| cashier | 0.00 → +0.2 | 0.24 | 0.47 | 0.44 |
| teacher | +0.01 → +0.2 | 0.12 | 0.38 | 0.19 |

## 9. 쉬운 용어 정리 (발표 중 한 번씩만 설명)

| 용어 | 쉬운 설명 |
|---|---|
| 벡터 | 숫자 여러 개를 묶은 좌표. 공간 속의 점이자 화살표 |
| 텍스트 인코더 | 문장을 벡터로 바꾸는 AI의 '읽는' 부분 |
| U-Net | 노이즈를 조금씩 지우며 그림을 만드는 부분 |
| VAE 디코더 | 완성된 그림을 실제 픽셀 이미지로 바꾸는 부분 |
| 성별 방향 | 남성 단어와 여성 단어를 가르는 벡터 공간 속 화살표 |
| 투영(projection) | 어떤 단어가 성별 화살표 방향으로 얼마나 가 있는지 재는 값. 양수면 남성 쪽 |
| lam | 성별 축 위의 위치. −1 여성 단어 평균, 0 가운데, +1 남성 단어 평균 |
| PCA | 여러 데이터를 가장 잘 요약하는 대표 방향을 찾는 방법 |
| 층(layer) | 텍스트 인코더가 문장을 12단계에 걸쳐 처리하는데, 그 각 단계 |
| 시드 | 이미지 생성의 랜덤 시작값. 같으면 같은 구도가 나온다 |
| CLIP | 이미지와 문장이 얼마나 어울리는지 재는 AI. 여기서는 성별 판정에 사용 |
| 무작위 방향 | 비교용 대조군. "아무 방향이나 움직여도 바뀌는 것 아니냐"는 반론을 막는다 |
| 클리핑 | 값이 정해진 범위를 벗어나면 가까운 경계로 잘라 맞추는 것 |

## 10. 한계 (15번 슬라이드)

- 직업 6개, 영어 프롬프트 하나로만 실험했다
- 성별 판정을 사람이 아니라 CLIP이 했다 ("사람 없음" 13.4%는 제외하고 계산)
- 성별을 남/여 둘로만 다뤘다
- 클리핑은 직업 6개, 범위 하나(+0.2 ~ +0.4)로만 시험했다

## 11. 예상 질문과 짧은 답

- **"왜 U-Net은 안 건드렸나요?"** → 텍스트 쪽은 단어 쌍으로 방향을 정의하고 검증할 수 있어서 해석이 쉽다. U-Net에도 편향이 있을 수 있고, Discussion의 결과가 그 가능성을 보여 준다
- **"56.8%면 절반 정도인데 충분한가요?"** → 7개가 제각각이면 약 14% 수준이라 한 방향으로 꽤 모여 있는 편이다. 그리고 처음 보는 단어 3쌍이 모두 맞게 갈렸다
- **"그냥 우연 아닌가요?"** → 무작위 방향으로 같은 거리만큼 움직이면 결과가 거의 안 바뀐다(차이 최대 3%p)
- **"CLIP 판정을 믿을 수 있나요?"** → 사람 이미지 중 88%는 확신도 0.9 이상이고, 그것만 써도 남성 비율 차이는 평균 2.3%p
- **"그럼 편향을 고칠 수 있나요?"** → 숫자상 50:50은 만들 수 있지만, 직업마다 필요한 값이 달라 하나의 규칙으로는 안 된다. 범위로 자르는 클리핑만으로도 편차를 약 40% 줄였다
- **"왜 클리핑 범위를 +0.2 ~ +0.4로 했나요?"** → 05에서 반반 지점이 +0.18~+0.45였기 때문에 그 가운데(+0.3)를 중심으로 잡았다
- **"teacher는 왜 예측과 다른가요?"** → 이번 실험으로는 원인을 알 수 없다. 예측은 lam 0과 +0.5 두 점 사이를 직선으로 이은 값이라 그 사이가 직선이 아니면 어긋날 수 있다
- **"클리핑하면 편향이 없어지나요?"** → 아니다. 폭은 줄었지만 CEO·pilot은 0.80~0.82, 나머지는 0.19~0.44로 직업 간 차이가 남는다
- **"이미지가 망가지진 않나요?"** → 직업다운 정도(CLIP score)는 대부분 유지됐다. nanny를 남성 쪽 끝으로 밀었을 때 가장 크게 떨어졌다(23.3 → 20.6). 백업 그림 `figures/clip_score.png`
